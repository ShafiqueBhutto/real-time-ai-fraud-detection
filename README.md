# Real-Time AI Fraud Detection & Risk Intelligence Platform

A portfolio-grade real-time fraud detection and risk intelligence platform built with modern Machine Learning, Data Engineering, MLOps, backend, and cloud technologies.

## Project Status

🚧 Under active development

## Planned Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- PyTorch
- Apache Kafka
- Apache Spark / PySpark
- MLflow
- ONNX
- ONNX Runtime
- FastAPI
- PostgreSQL
- Docker
- GitHub Actions
- AWS

## Architecture

The system will consume financial transaction events in real time, generate behavioral and transaction-level features, perform ML-based fraud detection, calculate explainable risk scores, generate alerts, and expose the results through REST APIs and a monitoring dashboard.

## Development Approach

The project is being developed incrementally with testing, reproducibility, monitoring, CI/CD, and production deployment considerations.
